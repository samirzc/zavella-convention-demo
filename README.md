# Zavella Convention App: NASCAC XIV demo

Single-file convention web app (`index.html`), deployed with Cloudflare Pages (no build step).

- Demo clock opens at Saturday 11:15 AM mid-convention. Tap the time pill to jump to other moments.
- `?demo=0` … `?demo=6` opens a specific moment, `?live` uses the real clock.
- Speaker names and committee contacts are fictional.
